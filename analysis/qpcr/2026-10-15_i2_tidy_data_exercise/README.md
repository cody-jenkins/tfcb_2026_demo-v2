### Tidy Data Exercise

The two plate sheets hold qPCR Cq values from U937 cells with GCN1 knockout, treated for 6 hours with homoharringtonine (HHT) at two concentrations or DMSO.
Each plate was read as a plate layout. The labels above and beside the grid describe each well.

Task: combine both plates into one tidy table, with one row per well and these columns:
plate, well, amplicon, sgrna, treatment, cq, note

Record the comment written below a plate in the note column of the well it describes. Leave other notes empty.
Do not calculate anything. Save the result as tidy_data.csv

# Analysis for the Tidy Data Exercise

I downloaded the excel file and reorganized the qPCR data file. It was presented in the default format given by the plate reader at the time of experimental data collection. However, that is not the most efficient way to store data for long term reference (it is untidy). To make it easier to refer back to down the road with less context, I reorganize the data such that each variable forms a column and each observation forms a row. Together the data is formed in a table which makes up one observational unit. I did this using the software microsoft excel.
